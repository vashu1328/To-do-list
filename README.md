# To-do-list

This is a simple To-Do List web application built using HTML, CSS, and JavaScript.  
The project helps users manage daily tasks by adding, removing, and organizing items in a list.

## Features

- Add new task
- Delete task
- Simple UI design
- Responsive layout
- Easy to use
- Beginner friendly project

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

To-do-list/
│── index.html  
│── style.css  
│── script.js  
│── README.md  

## 🎯 Purpose of Project

This project is created for practicing JavaScript DOM manipulation and frontend development.  
It is useful for beginners who want to learn basic web development.
